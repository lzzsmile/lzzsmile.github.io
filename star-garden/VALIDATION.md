# 星愿花园 0.2.1 · 设置与焦点修复

验证日期：2026-11-12。仅本机修改，未提交、推送或发布。

## 本次修复与根因

- 原图蓝框边界与 `#main` 一致，并非卡片边框。原 `show()` 保存 `document.activeElement`，`close()` 无条件对其调用 `focus()`；Safari 触摸按钮不保证按钮获得焦点，可能保留在带 `tabindex="-1"` 的 `main` 上，关闭弹层就会把系统焦点环画到整个页面。
- 现在由实际操作按钮记录入口，嵌套弹层保留最初入口。保存或后台重绘后按操作、记录 ID 与控件样式重新定位；入口消失时回到当前导航，不对整页容器盲目聚焦。同一愿望的标题和右侧按钮会分别定位。
- 只有触摸/鼠标恢复的单个控件临时隐藏焦点环，下一次键盘操作立即恢复。Tab、Enter、Escape、输入框和跳到主要内容仍保留可见焦点；列表内焦点环不会被卡片裁切，选中衣服颜色的焦点也与选中状态区分。
- 「我的」去掉顶部头像和「我的星愿花园」重复入口，改成「个性化」「数据与使用」两个设置分组，直接提供专属陪伴、数据与备份、添加到主屏幕。底部保留本机存储提醒、版本和离线状态。
- 数据模型、存储键和备份格式不变。离线资源版本更新为 0.2.1，仅限星愿花园自身缓存。

## 手机优先界面

- 参照相邻念念应用的浅灰底、系统字体、单列列表和分组设置，去掉桌面侧栏、英文装饰与大段首页文案。
- 首页保留花园成长插画、简洁统计和陪伴角色。愿望一行一项，主要操作为拇指可点的圆形按钮。
- 四个固定底部标签：花园、愿望、印记、我的。新增、详情、打卡、庆祝、专属陪伴与备份在手机底部弹层中完成。
- 设置不再一次展示长表单；进入对应入口才编辑。输入字号为 16px，避免 iOS 输入聚焦自动放大；保留安全区与减少动态效果支持。
- 保留所有花园插画、角色衣服颜色、三种庆祝小剧场、印章、愿望归档、打卡撤销和备份恢复。

## 实际 Chromium 检查

独立、临时 Chromium 上下文，390×844、触摸模式、2 倍像素、中文、上海时区，22 组检查通过：

- 空白启动无数据写入；已有 v1 数据逐字节保留。
- 320、375、390、430、1280 宽度四个标签页无横向溢出。
- 专属称呼、衣服颜色的预览、取消、保存与刷新。
- 新愿望取消、Escape、焦点归还；完成一次愿望创建和刷新保留。
- 打卡取消不保存；完成后只生成一次待庆祝记录；弹层切换保持页面滚动锁。
- 庆祝关闭、刷新、继续、重选结局、收章与重放。
- 每日打卡限制、编辑、归档、重新种回、撤销取消与确认。
- 真实 JSON 下载；无效导入在弹层内显示错误；旧备份预览、取消、确认恢复与恢复导入前数据。
- 浏览器 Back/Forward 回到正确标签，并关闭未完成弹层。
- 320×568 底部弹层可滚动，表单无横向溢出，输入保持 16px。
- service worker 作用域保持 `/star-garden/`，断网后在标签页地址刷新成功。
- 无 JavaScript 异常，无第三方请求。

回归发现原 worker 未剥离导航 URL 的 `#wishes` 等片段，离线刷新会被入口白名单排除。现在仅在判断入口时去掉查询和片段，缓存仍隔离于花园目录，未扩大为任意页面拦截。
