# 星愿花园 0.4.1 · 不删 App 的更新与备份提醒

验证日期：2026-11-12。起始 HEAD 为 `90c6d2580f66f0e8db608357695dd72d4024cd1b`，工作区干净。本次仅修改本机文件，未提交、推送或发布。所有存储操作都在随机回环端口的隔离测试浏览器中使用虚构记录，未读取、清除或修改真实站点的浏览器记录。

## 可确认的原因与边界

- 旧 `app.mjs` 只在加载时注册 service worker，没有回到前台/恢复联网时的版本检查、待更新提示或切换版本后的刷新流程。因此在 iPhone 主屏幕中一直存活的旧页面不会因部署而自动替换已经执行的 JavaScript。
- 旧 worker 对未带版本的脚本/样式使用普通 network-first fetch，仍可能经过 HTTP 缓存；安装后立即 skipWaiting/claim，却不协调页面刷新。没有完整资源版本核对，存在页面、模块、样式不同步的风险。这些是代码能证明的问题，并非已取得用户 iPhone 上具体请求的证据。
- 愿望、照片、导入前恢复区、最近删除恢复区都只在同一浏览器的 localStorage 中，没有服务端或云端副本。主屏幕 App 与 Safari 的存储可能不同，删除 App、清除网站数据或浏览器回收存储可能导致本机记录消失。修复不承诺卸载后保留数据，也不把同一存储中的恢复区称为独立备份。
- 用户确认原有数据是测试数据，不需要恢复。本次没有尝试恢复真实设备数据。若数据已被删除且没有外部 JSON 备份，本应用无法从服务器恢复。

## 修复内容

- 首页与 document.title 统一为「星愿花园」，有主人称呼时为「XXX的星愿花园」。manifest 身份、start_url、scope、数据版本、存储键及 JSON 备份格式均保持不变。
- 「我的 → 版本与更新」展示当前页面版本、手动检查、更新并重新打开、导出备份与恢复说明。联网打开、回到前台、pageshow 与恢复网络会检查；前台重复触发限流，手动检查可重试。网络/安装失败不误报最新版。
- 新版本等待明确应用或旧窗口全部关闭，不在后台强制刷新。另一窗口应用新版只提示当前页，不丢失当前页未保存编辑。用户点击更新后若离开更新弹层并开始编辑，迟到的激活也不强制刷新。
- 每个版本预缓存完整资源，并通过 SHA-256 integrity 检查实际响应。安装绕过 HTTP 旧缓存；缺文件、HTTP 错误或内容不匹配会使安装失败，旧版本仍可使用。已安装页面、样式与模块从同一个完整 release cache 读取，避免在线请求混合发布版本。
- cache 名含版本和资源摘要。激活仅清理星愿花园自身且同目录的旧 Cache Storage，不清除 localStorage、IndexedDB、其他应用缓存，不注销已有安装。
- 处理离线首次启动后再联网、重复检查、检查超时、安装失败重试、正常 Worker 退役等边界。离线时仍可使用完整旧资源。
- 数据与备份、安装说明明确警示不要删除后重装来更新。安装/换设备前先导出并确认 JSON 文件已保存在「文件」App 等独立位置，再导入恢复；备份包含照片且未加密。

## 照片与裁剪

- 单张输入上限提高到 30 MiB（界面明确为 30 × 1024 × 1024 字节）。支持 JPEG、静态 PNG 与静态 WebP；无 MIME 的 JPG/PNG/WebP 文件可按扩展名识别，但仍必须通过实际格式头验证。
- 选择照片后出现正方形裁剪预览。支持鼠标/触摸拖动、1–4 倍缩放、水平/垂直位置滑杆、方向键移动和重置；「使用此裁剪」只更新预览，最终点击设置「保存」才持久化。
- 取消裁剪保留此前形象和未保存的称呼；取消整个设置、关闭、切换默认形象、刷新或较早上传的异步结果均不会悄悄保存照片。裁剪期间禁用设置保存。
- 解码前验证格式、单边不超过 16384、总像素不超过 5000 万。HEIC/HEIF、GIF、SVG、RAW 等不支持格式有明确说明；动态 WebP 与 APNG 在解码前拒绝，避免多帧图片突破内存预算。PNG 动画检查遍历整个文件的块头而不读完整压缩像素，最多 4096 个块。
- 优先通过可终止的本地 Worker 解码，最长边缩至 2048，20 秒超时或取消即终止线程。旧请求不能阻塞之后选择，解码队列串行；Worker 不可用时，仅对 2000 万像素以内照片使用 Image，随后一次缩小至最长边 2048 并释放原图。
- iPhone 常见 JPEG EXIF 方向被正确应用；方向解析兼容 JPEG 填充标记。输出只保留裁剪后的像素，最长边 512，JPEG 数据 URL 不超过 350 KiB，不保存文件名、EXIF/GPS。对象 URL、ImageBitmap、Canvas 与线程在完成或取消后释放。
- 照片全程只在本机处理，不上传，也不依赖联网转换服务。HEIC/HEIF 需先导出 JPEG；不能保证所有手机浏览器都能处理 48MP 原图，浏览器不支持安全缩小解码时会提示先缩至 20MP。

# 星愿花园 0.2.1 · 设置与焦点修复

验证日期：2026-11-12。仅本机修改，未提交、推送或发布。

## 本次修复与根因

- 原图蓝框边界与 `#main` 一致，并非卡片边框。原 `show()` 保存 `document.activeElement`，`close()` 无条件对其调用 `focus()`；Safari 触摸按钮不保证按钮获得焦点，可能保留在带 `tabindex="-1"` 的 `main` 上，关闭弹层就会把系统焦点环画到整个页面。
- 现在由实际操作按钮记录入口，嵌套弹层保留最初入口。保存或后台重绘后按操作、记录 ID 与控件样式重新定位；入口消失时回到当前导航，不对整页容器盲目聚焦。同一愿望的标题和右侧按钮会分别定位。
- 只有触摸/鼠标恢复的单个控件临时隐藏焦点环，下一次键盘操作立即恢复。Tab、Enter、Escape、输入框和跳到主要内容仍保留可见焦点；列表内焦点环不会被卡片裁切，选中衣服颜色的焦点也与选中状态区分。
- 「我的」去掉顶部头像和「我的星愿花园」重复入口，改成「个性化」「数据与使用」两个设置分组，直接提供专属陪伴、数据与备份、添加到主屏幕。底部保留本机存储提醒、版本和离线状态。

## 实际 Chromium 检查

独立、临时 Chromium 上下文，390×844、触摸模式、2 倍像素、中文、上海时区，22 组检查通过：

- 空白启动无数据写入；已有 v1 数据逐字节保留。
- 320、375、390、430、1280 宽度四个标签页无横向溢出。
- 专属称呼、衣服颜色的预览、取消、保存与刷新。
- 新愿望取消、Escape、焦点归还；完成一次愿望创建和刷新保留。
- 打卡取消不保存；完成后只生成一次待庆祝记录；弹层切换保持页面滚动锁。
- 庆祝关闭、刷新、继续、重选结局、收章与重放。
- 每日打卡限制、编辑、归档、重新种回、撤销取消与确认。
- 真实 JSON 下载；无效导入在弹层内显示错误；旧备份预览、取消、确认恢复与恢复导入前数据。
- 浏览器 Back/Forward 回到正确标签，并关闭未完成弹层。
- 320×568 底部弹层可滚动，表单无横向溢出，输入保持 16px。
- service worker 作用域保持 `/star-garden/`，断网后在标签页地址刷新成功。
- 无 JavaScript 异常，无第三方请求。

回归发现原 worker 未剥离导航 URL 的 `#wishes` 等片段，离线刷新会被入口白名单排除。现在仅在判断入口时去掉查询和片段，缓存仍隔离于花园目录，未扩大为任意页面拦截。
